# Security

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/ParkWardRR/birdnet-snapshot/security/advisories/new), not public issues.

In scope: anything that makes a snapshot publish data a logged-out BirdNET-Go guest could not see (settings, credentials, stream URLs, skipped audio), anything that lets a snapshot visitor reach the BirdNET-Go server, and leaks of the Bunny storage password.
